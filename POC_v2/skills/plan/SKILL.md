# Plan

Read the task, current workspace, and available run artifacts. Do not modify the
implementation.

Write `plan.md` in the run's artifact directory. State the intended change,
affected areas, verification approach, and any important rollback or safety
considerations. Keep the plan proportional to the task.

Choose `complete` when the work is actionable and testable. Choose `blocked`
when a decision or prerequisite is missing.
