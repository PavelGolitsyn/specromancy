Implementation, refactoring, and packaging/namespace migration are all parts of
the 0.1.0 implementation. The `migration/` directory records the source-layout,
namespace, and packaging stages of that implementation.

These documents retain the design context and verification evidence for earlier
work. Links and test paths follow the current repository layout, but historical
module names, counts, and outcomes describe the work as recorded. Build artifacts
are identified by implementation stage and original hash; command excerpts use
explicit artifact-path placeholders where filenames have been omitted.
For current behavior and ownership, use the [documentation index](../README.md).
